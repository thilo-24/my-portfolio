## Overview

A performance-focused web application built with modern static rendering and client-side interactivity.

### Features

* **Instant Load Times:** Zero-JavaScript rendering by default using Astro islands.
* **Responsive Layout:** Tailored layouts for desktop, tablet, and mobile displays.
* **Type-Safe Data:** Driven by Astro Content Collections and TypeScript validation.
